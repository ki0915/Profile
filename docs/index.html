보안, 인프라, AI 보안 엔지니어

미디어솔루션에서 1년 11개월 동안 병역특례 산업기능요원으로 근무하며 대형병원, 대형 컨벤션센터, 5성급 호텔 등 4개 기업 고객의 키오스크 CMS와 운영 서버를 개발하고 운영했습니다. 고객 시스템에서 일어난 침해사고 두 건을 현장에서 대응했고, 웹 애플리케이션을 AWS에 다시 구축하며 외부에서 접근할 수 있는 경로를 줄였습니다. 지금은 개인 프로젝트로 AI 관련 보안 도구를 만들고 있습니다. LLM과 MCP 통신에서 개인정보와 기밀이 새어 나가지 않게 막는 프록시, 정적분석과 LLM 검증을 묶은 취약점 스캐너가 그 예입니다.

    보안 사례, 2023.04–2025.03
  2. 대형병원 키오스크 CMS의 권한 결함 수정과 보안점검 대응

    대형병원 키오스크를 원격으로 관리하는 CMS를 혼자 만들어 운영했고, 세션 검증보다 권한 부여가 먼저 일어나던 결함을 고쳐 병원 보안점검을 통과했습니다.

    보안 사례, 2023.04–2025.03
  3. ETK-Scanner, 비용 상한이 있는 LLM 소스코드 취약점 진단

    정적분석으로 의심 구간을 먼저 좁히고 LLM 검증은 필요한 곳에만 쓰는 취약점 스캐너를 만들어, 실습 백엔드와 오픈소스의 권한 문제를 찾았습니다.

    도구 사례, 2026.07
  4. Mcp-Guard, LLM과 MCP 통신의 개인정보 유출 방지 프록시

    LLM과 MCP 도구로 나가는 요청에서 주민등록번호와 API 키 같은 민감 정보를 찾아 가리거나 막는 프록시를 만들었습니다.

    도구 사례, 2026.07
  5. EvidScope, AI 행동을 감사할 수 있게 근거를 묶는 파일럿

    AI가 한 행동과 그때의 권한, 정책, 근거 문서, 사람의 판단을 서명 원장으로 이어 붙여 감사 담당자가 대조할 수 있게 한 로컬 파일럿입니다.

    도구 사례, 2026.09–2026.10
  6. 서버 7대 통합과 여러 겹의 백업 설계

    노후 서버 7대를 Hyper-V로 합치며 외부에서 바로 들어오던 원격 접속을 없애고, 스냅샷 하나에 기대던 복구를 여러 겹의 백업으로 바꿨습니다.

    보안 사례, 2023.04–2025.03
  7. 5성급 호텔 서버의 디스크 고갈 장애와 재발 방지

    배포 때마다 쌓인 Docker 이미지와 중지된 컨테이너가 디스크를 채워 서비스가 멈춘 장애를 복구하고, 주기 정리를 자동화해 같은 원인의 장애를 막았습니다.
