도구 사례2026.07

Mcp-Guard, LLM과 MCP 통신의 개인정보 유출 방지 프록시

LLM과 MCP 도구로 나가는 요청에서 주민등록번호와 API 키 같은 민감 정보를 찾아 가리거나 막는 프록시를 만들었습니다.

역할
정책과 탐지 설계, 구현, 검증

풀려던 문제

생성형 AI를 업무에 쓰면 사람이 붙여 넣은 문서나 로그에 개인정보와 시크릿이 섞이기 쉽습니다. MCP 서버는 표준 입출력으로 JSON-RPC 메시지를 주고받는 경우가 많습니다. 그래서 네트워크 경계에 둔 HTTP 프록시만으로는 내용을 볼 수 없습니다.

문제를 확인한 방법

처음 버전은 원문 그대로만 검사했고, 띄어 쓴 주민등록번호나 전각 숫자, Base64로 감싼 값이 그대로 통과했습니다. 우회 기법을 넣은 합성 데이터로 그 차이를 쟀습니다.

고른 설계와 이유

HTTP 프록시와 stdio 어댑터에 같은 정책을 적용해 두 경로의 판단이 같게 했습니다. 검사는 원문 위치를 유지한 파생 문자열로 하고, 마스킹은 원래 입력의 해당 범위에 적용했습니다. 판단이 어려우면 막고, 감사 로그에는 원래 값을 남기지 않게 했습니다.

직접 설계하고 만든 것

  • HTTP 리버스 프록시는 요청과 응답 본문, URL, SSE 이벤트를 검사하고, stdio 어댑터는 MCP의 줄 단위 JSON-RPC를 같은 정책으로 검사합니다.
  • 주민등록번호는 날짜와 검증 숫자로, 카드번호는 IIN과 Luhn 검사로, 계좌번호는 앞뒤의 은행 문맥으로 확인합니다.
  • 유니코드 NFKC 정규화, 숫자 사이 공백과 보이지 않는 문자 제거, 크기를 제한한 Base64 디코딩으로 우회 표현을 풀어 검사합니다.
  • 정책 스키마 검증과 시크릿 분리, 만료 시간이 있는 허용 예외, Prometheus 지표, Dockerfile과 Helm 차트를 만들었습니다.

함께 쓰고 고친 과정

우회 사례와 테스트 초안은 Claude Code와 Codex의 제안을 참고했습니다. 탐지와 정책 기준, 정규화 방식, 구현 검토와 최종 반영은 직접 판단했습니다.

검증 방법

우회 기법을 넣은 합성 데이터로 정규화 전후의 탐지 수와 오탐을 비교했습니다. 합성 데이터는 민감 사례와 정상 사례로 나눴습니다. 프록시를 거칠 때 늘어나는 지연은 로컬에서 같은 요청을 짝지어 비교했습니다.

기능 명세

기능하는 일확인
HTTP 리버스 프록시외부 LLM API로 가는 요청과 돌아오는 응답을 받아 경로, 쿼리, 본문과 SSE 스트림을 검사한 뒤 정책에 맞게 내보냅니다.로컬 환경에서 1,102바이트 요청 200쌍을 비교해, 프록시를 거칠 때 평균 3.10ms가 더 걸리는 것을 측정했습니다.
stdio 어댑터표준입출력으로 한 줄씩 오가는 MCP의 JSON-RPC 요청과 응답을 받아 HTTP 프록시와 같은 정책으로 검사합니다.
개인정보 탐지주민등록번호는 날짜와 검증 숫자로, 카드번호는 IIN과 Luhn 검사로, 계좌번호는 앞뒤의 은행 문맥으로 확인해 가리거나 막습니다.
시크릿과 보호값 탐지API 키는 알려진 접두어와 엔트로피로 찾고, 조직이 등록한 보호값은 원문이나 SHA-256 해시와 일치하면 막거나 가립니다.
우회 표기 정규화유니코드 표기 차이와 숫자 사이의 공백, 보이지 않는 문자를 정리하고 Base64는 크기를 제한해 한 번만 풀어 검사합니다.우회 기법을 넣은 합성 데이터로 정규화 전후의 탐지 수를 비교했습니다.
정책과 감사 기록설정 스키마를 검증하고 시크릿을 설정과 분리하며, 기한이 있는 허용 예외와 원래 값을 뺀 감사 로그, Prometheus 지표를 제공합니다.

시연

만든 방법

  1. 가로채기HTTP 리버스 프록시와 stdio 어댑터가 외부로 나가는 요청과 돌아오는 응답을 중간에서 받습니다.
  2. 정규화NFKC 정규화와 숫자 구분자 정리, 크기를 제한한 Base64 디코딩으로 검사할 문자열을 만듭니다.
  3. 탐지규칙마다 형식과 검증 숫자, 주변 문맥을 확인하고, 정규화한 문자열에서 찾은 위치를 원문 범위로 되돌립니다.
  4. 정책 적용규칙에 정한 대로 원문을 가리거나 전송을 막거나 경보를 남기며, 판단할 수 없으면 차단합니다.
  5. 기록원래 값을 남기지 않는 감사 로그와 Prometheus 지표를 쌓습니다.
