소개

게시판과 권한별 접근 제한, 실시간 채팅을 갖춘 위키 서비스를 프론트엔드부터 백엔드까지 직접 만든 2023년 개인 프로젝트입니다.

TypeScript와 Express로 API 서버를, Angular로 클라이언트를 나눠 만들었습니다. 게시글 CRUD와 파일 업로드, JWT 인증과 bcrypt 비밀번호 해시, 역할별 권한을 구현했고, Socket.IO 채팅을 직접 붙였습니다.

주요 기능

실시간 채팅
Socket.IO로 받은 메시지를 Chat 모델에 저장하고, 방마다 receiveMessage 이벤트로 참여자에게 전달합니다.
게시글과 파일 업로드
게시글 CRUD API와 파일 업로드를 제공하며, 긴 게시글이 저장되도록 저장 형식을 STRING에서 TEXT로 바꿨습니다.
권한별 접근 제한
역할 등급에 따라 기능을 나눠, 게시글 삭제는 권한 3 이상 사용자만 할 수 있게 했습니다.
요청 보호와 운영 구성
helmet과 hpp 미들웨어를 적용하고, Docker Compose와 PM2, Winston으로 배포와 로그를 구성했습니다.
