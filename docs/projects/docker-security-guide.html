Docker 컨테이너 보안 가이드

OWASP Docker Top 10, CIS Docker Benchmark, NIST SP 800-190을 위험도와 구현 비용 기준으로 다시 묶어, 먼저 할 일과 나중에 할 일을 나눈 가이드입니다.

저장소 github.com/ki0915/Docker-Security-Guide

요약

컨테이너 보안 기준은 문서마다 항목이 많고 순서가 달라서, 작은 팀이 어디서부터 손대야 할지 정하기 어렵습니다. OWASP Docker Top 10, CIS Docker Benchmark, NIST SP 800-190을 함께 놓고 D01부터 D10까지의 대응을 위험도와 구현 비용으로 다시 정렬했습니다. 항목마다 설정 예시와 설명을 붙여 GitHub에 공개했습니다.

배경

세 기준은 겹치는 내용이 많지만 항목 이름과 순서, 상세 수준이 다릅니다. 하나씩 따라 하다 보면 효과가 큰 설정과 손이 많이 가는 설정이 뒤섞입니다.

한 일

이미지와 빌드

  • 베이스 이미지를 최소화하고 태그 대신 digest로 고정하는 방법을 정리했습니다.
  • CI에서 Trivy로 이미지 취약점을 검사하는 예시를 넣었습니다.
  • BuildKit 시크릿으로 빌드 중 비밀값이 이미지 레이어에 남지 않게 하는 방법을 설명했습니다.

실행 권한과 격리

  • non-root 실행, capability 제거, rootless 모드를 설정 예시와 함께 다뤘습니다.
  • 컨테이너 사이 네트워크를 필요한 범위로 나누는 방법을 정리했습니다.

런타임 감시

  • cAdvisor로 자원 사용을 보고, Falco로 컨테이너 안의 이상 행동을 잡는 구성을 설명했습니다.

결과

D01부터 D10까지 항목마다 위험도와 구현 비용, 설정 예시를 붙인 가이드를 공개 저장소에 올렸습니다.

가이드에 정리한 도구를 모두 운영 환경에 도입했다는 뜻은 아닙니다.
