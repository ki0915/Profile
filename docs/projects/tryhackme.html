프로젝트

TryHackMe 모의 침투 실습과 보고서

소개

허가된 워게임 환경에서 모의 침투를 연습하고, 공격 경로와 개선 방안을 보고서로 정리한 학습 기록입니다.

TryHackMe의 Jr Penetration Tester 경로와 웹 해킹 모듈을 실습했습니다. 정찰부터 침투, 권한 상승, 개선 권고까지를 OSCP 보고서 양식으로 작성하며 보고서 쓰는 연습을 했습니다.

주요 기능

서비스 열거와 연계 분석
Nmap으로 서비스를 열거하고, SMB 익명 접근과 IIS 공유 디렉터리 설정 오류가 이어지는 경로를 분석했습니다. 권한 상승 경로까지 실습해 보고서로 남겼습니다.
웹 취약점 실습
SQL 인젝션, XSS, IDOR 등 웹 해킹 모듈을 Burp Suite로 실습했습니다.
Active Directory 학습
Active Directory 구성과 Kerberos, NetNTLM 인증 방식을 학습해 정리했습니다.
