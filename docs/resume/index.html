Mcp-Guard

LLM과 MCP 통신의 민감정보 유출을 막는 DLP 프록시
  • 외부 LLM이나 MCP 서버와 주고받는 요청과 응답을 중간에서 검사하여 개인정보와 기밀이 밖으로 나가지 않게 막는 DLP 프록시를 구현하였습니다. MCP 통신이 HTTP와 표준입출력 두 경로로 오가기 때문에 두 경로에 같은 정책을 적용하였고, 감사 로그에는 원래 값을 남기지 않게 하였습니다.
  • 단순한 우회를 막기 위해 유니코드 정규화와 크기를 제한한 Base64 디코딩을 넣었고, 그 결과 우회 기법을 넣어 만든 합성 데이터 90건 시험에서 민감 사례 60건의 탐지가 10건에서 56건으로 늘었으며 정상 30건에서는 오탐이 없었습니다.

ETK-Scanner

정적분석과 LLM을 결합한 저비용 취약점 스캐너
  • 모든 코드를 LLM으로 분석하면 API 비용이 커지기 때문에, 정적분석으로 후보를 먼저 추출한 뒤 후보에만 저비용 LLM 분류와 고비용 LLM 검증을 차례로 적용하고 예산 상한에 닿으면 검사를 멈추는 단계별 파이프라인을 구현하였습니다. 후보 추출에는 Python은 AST를, JS와 TS는 정규식을 썼습니다.
