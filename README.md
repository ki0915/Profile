## Structure

- `docs/index.html` — 소개, 프로젝트 목록, 경력과 자격
- `docs/projects/*.html` — 프로젝트별 요약, 자세한 설명, 명세(기간, 구분, 역할, 기술, 저장소)
- `docs/site.css`, `docs/fonts/` — 화면 스타일과 글꼴
- `docs/resume-ko.pdf`, `docs/portfolio.pdf` — 이력서와 포트폴리오 PDF

The project is published with GitHub Pages. The root `index.html` redirects to the `docs/` site.
